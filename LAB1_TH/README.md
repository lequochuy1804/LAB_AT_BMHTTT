Họ và tên: Lê Quốc Huy

Học phần: An toàn và Bảo mật thông tin

1. Mục tiêu thực hành

Tìm hiểu nguyên lý hoạt động của các thuật toán mã hóa đối xứng cổ điển.

Xây dựng chương trình mã hóa và giải mã bằng 6 thuật toán: Caesar, Vigenère, Rail Fence, Playfair, Transposition và Autokey.

Sử dụng Java Swing và NetBeans GUI Builder để thiết kế giao diện cho từng thuật toán.

Xây dựng chương trình tổng hợp cho phép lựa chọn và thực hiện các phương pháp mã hóa, giải mã.

Kết nối Microsoft SQL Server để lưu trữ, quản lý và truy xuất lịch sử mã hóa.

Thực hiện phân tích, tấn công mật mã cổ điển nhằm tìm hiểu những điểm yếu của các thuật toán.

Kiểm thử các chức năng, đối chiếu kết quả với dữ liệu mẫu và đánh giá kết quả thực hành.

2. Công nghệ sử dụng

Ngôn ngữ: Java

Giao diện: Java Swing

IDE: Apache NetBeans

Quản lý dự án: Maven

Cơ sở dữ liệu: Microsoft SQL Server

Công cụ quản lý CSDL: SQL Server Management Studio (SSMS)
