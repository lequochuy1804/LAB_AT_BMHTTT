# LAB 10 – Remote DNS Cache Poisoning

- **Họ tên:** Lê Quốc Huy
- **MSSV:** 1150070016


## 1. Mục tiêu thực hành

- Tìm hiểu nguyên lý tấn công đầu độc bộ nhớ đệm DNS từ xa.
- Phân biệt DNS spoofing trong cùng mạng với remote DNS cache poisoning.
- Sử dụng pfSense để tách mạng DNSLAB và ATTACKNET.
- Phân tích vai trò của Transaction ID, UDP source port, bản ghi NS và glue A.
- Tìm hiểu cách kiểm chứng kết quả và các biện pháp bảo vệ DNS resolver.
